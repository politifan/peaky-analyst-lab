# Словарь учебных данных

Все данные синтетические. CSV UTF-8, разделитель запятая, заголовок в первой строке. Пустое поле — неизвестное, а не ноль. Идентификаторы в Python/таблице читают как текст. Денежные поля — целые копейки своей currency. Время примеров — ISO UTC с Z.

| Файл | Ключ строки | Поля и смысл |
| --- | --- | --- |
| orders.csv | order_id | customer_id — покупатель; amount_cents — сумма заказа; currency — RUB/USD; status — paid/cancelled; created_at — время заказа |
| refunds.csv | refund_id | order_id — существующий заказ; amount_cents — неотрицательная сумма отдельного возврата в валюте заказа. Несколько возвратов одного заказа допустимы |
| customers.csv | customer_id | channel — канал. Отсутствие клиента и пустой channel найденного клиента — разные ошибки/состояния |
| project-orders.csv, project-refunds.csv | те же ключи | Изменённый набор итоговой работы. Использует общий customers.csv. check-basic запускают с --project |
| items.csv | item_id | order_id, sku, qty и bought_at: товарная строка. Её сумма не включает все возможные компоненты заказной суммы |
| prices.csv | price_id | sku, valid_from, valid_to, price_cents. Интервал [from,to), пустой valid_to — открытый конец. На покупку нужна ровно одна цена |
| events.csv | event_id | user_id, event_type view/buy, event_at, loaded_at. Суммы здесь нет. Несколько событий одного пользователя не становятся несколькими пользователями |
| batches/first.csv | event_id | Первые четыре события; стартовый V1 для практик обновления |
| batches/late.csv | event_id | Один полный повтор и два новых ключа 5/6. Ключ 5 пришёл 4 января с event_at 2 января. После объединения с first — шесть ключей |
| experiments/assignments.csv | user_id | variant A/B, assigned_at, exposed 0/1, converted_at. Окно результата — семь суток от назначения, зрелость и правило экспозиции оговаривают до эффекта |
| experiments/assignments-double-user-example.csv | намеренно нарушен user_id | Маленький пример двух вариантов одному человеку; только диагностика назначения |

first-report.xlsx — отдельный первый арифметический пример, одна строка на заказ, первоначальный итог 980 коп. и 882 после учебной комиссии. Это не итог orders.csv.

## Выход денежного отчёта
Порядок: order_id,customer_id,channel,currency,amount_cents,refunded_cents,net_cents. Популяция paid RUB, возвраты сначала сворачиваются до order_id, неизвестные суммы остаются неизвестными. Один order_id встречается один раз. check-basic сравнивает результат с pandas и отдельным CSV/SQLite путём из тех же файлов. Команда lab.py sql использует фиксированный учебный sql/schema.sql: произвольное изменение CSV не меняет эту схему автоматически.

## Состояние практик pipeline
Для цепочки first → повтор → конфликт в новом файле → отказ late до CURRENT → успешный late нужна новая распакованная копия. Не редактируют уже зарегистрированные пакеты или опубликованные версии. Сохраняют V1 до новых пакетов. На вкладке панели «Заказы» фиксирована paid RUB; фильтруется channel. Вкладка «События» показывает version/max_loaded_at и события выбранной версии. Полнота периода не доказывается последним временем загрузки.
