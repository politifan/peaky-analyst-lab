# Вопрос
Какое решение поддерживает отчёт?

## Определение
Объект строки, период, зона, валюта, числитель/знаменатель, пропуски.

## Источники и повтор
Имена файлов, SHA256, версия расчёта, команды запуска.

## Результат
Числа с единицами, сравнение, график с подписью и текстовым описанием.

## Проверки
Ключи, полные дубли/конфликты, границы, пустота, независимая сверка.
